## D) How to run it

From `/home/steve/.openclaw/workspace/strands_agent`:

```bash
.venv/bin/pytest -q
.venv/bin/python -m strands_agent_tui.app
```

In the app:
- press `F11` to open the session switcher,
- press `T` for tool triage or `G` for intervention triage,
- inspect the backlog headers before opening a session,
- use `[` / `]` if enough saved sessions exist to page through the backlog.

You can also inspect the launch-time picker directly:

```bash
.venv/bin/python -m strands_agent_tui.app --pick-session --pick-filter tool
.venv/bin/python -m strands_agent_tui.app --pick-session --pick-filter intervention
```
