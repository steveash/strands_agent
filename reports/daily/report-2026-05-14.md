## D) How to run it

From `/home/steve/.openclaw/workspace/strands_agent`:

```bash
.venv/bin/pytest -q
.venv/bin/python scripts/approval_smoke.py
.venv/bin/python -m strands_agent_tui.app
```

In the app:
- press `F11` to open the session switcher,
- press `P` for pending approvals or `D` for denied approvals,
- inspect the backlog headers before opening a session,
- use `[` / `]` when enough saved sessions exist to page backlog summaries.
