## D) How to run it
```bash
cd /home/steve/.openclaw/workspace/strands_agent
. .venv/bin/activate

# launch the TUI
strands-agent

# inside the TUI:
# - F1/F2/F3/F4/F5/F12 change timeline filters
# - Ctrl+T toggles detail
# - Ctrl+R toggles raw data
# - Ctrl+Up / Ctrl+Down move the spotlighted event
# - Ctrl+O toggles spotlight mode on/off

# standalone spotlight walkthrough
python scripts/timeline_smoke.py

# full suite
pytest -q
```
