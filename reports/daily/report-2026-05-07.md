## B) Why this step matters for understanding Strands

This makes the steering layer more legible.

A denied test approval means the Strands loop is blocked before execution, while a failed test run means the tool executed and produced a failing outcome. Surfacing that distinction in saved-session triage makes it easier to study where steering intervenes versus where runtime work actually breaks.
