## B) Why this step matters for understanding Strands

This prototype is trying to make the agent loop, tool queue, and steering state visible instead of implicit.

Pending approvals are part of the live Strands workstation state, especially when a session matches a lane only because a tool request is queued but not yet executed. Before this change, page-level rollups showed that context, but the selected-session preview still made the operator infer where the age cue came from.

This refinement matters because it makes one more piece of the Strands mental model explicit:
- queued tool work is real agent state,
- provenance of state matters,
- and fallback logic should be inspectable in the UI, not hidden in helper code.
