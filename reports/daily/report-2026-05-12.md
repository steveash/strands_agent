## D) How to run it

From `/home/steve/.openclaw/workspace/strands_agent`:

```bash
.venv/bin/pytest -q
.venv/bin/python scripts/session_picker_smoke.py
.venv/bin/python scripts/session_switcher_smoke.py
.venv/bin/python -m strands_agent_tui.app --help | grep -E -- '--pick-filter|workspace-inspect|workspace-edit|shell-inspect|shell-test|shell'
.venv/bin/python -m strands_agent_tui.app --pick-session --pick-filter shell
```

Useful keys in the picker or switcher:
- `W` → workspace inspect
- `E` → workspace edit
- `H` → shell
- `I` → shell inspect
- `Y` → shell test
- `A` → all sessions
