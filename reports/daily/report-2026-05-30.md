   - Updated smoke-script tests now assert the exact stderr ordering for the early `all-review` failure path while keeping the persisted `matrix-summary.json` artifact contract covered.

## B) Why this step matters for understanding Strands

This prototype is using smoke wrappers and artifact bundles to make the Strands workflow inspectable, not just runnable.

The `all-review` path is especially interesting because it can fail before the docs-review lane ever executes. Persisting metadata was already useful, but operators still had to parse JSON to find the bundle root manually. With direct artifact lines now emitted on the early-failure path, the prototype better demonstrates an important Strands-adjacent lesson:
- resumable or deferred work should still leave obvious breadcrumbs,
- failure-mode observability matters as much as success-mode output,
- and machine-readable artifacts should be paired with human-usable stderr guidance.
